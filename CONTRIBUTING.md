# Contribuir

Gracias por querer contribuir. Lee estas reglas antes de enviar PRs.

1. Fork y crea una rama: `git checkout -b feature/nombre-corto`
2. Sigue Conventional Commits para mensajes de commit.
3. Añade tests si corresponde.
4. Abre un Pull Request describiendo objetivo, cambios y cómo probar.
5. Revisa el código para evitar incluir secretos.

Para cambios de seguridad usa el ISSUE_TEMPLATE/security_report.md.
